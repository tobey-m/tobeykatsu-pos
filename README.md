# tobeykatsu-pos

Interactive, static prototype for exploring the tobeykatsu restaurant POS workflow.

## Prototype screens

- **Overview:** sample sales, open tables, and low-stock reminders.
- **POS:** choose a table and add items to an open bill. The QR customer preview adds to the same table.
- **Kitchen:** accept new orders and advance their status.
- **Inventory:** sample purchase/use units, minimum-stock alerts, and waste logging.
- **Cost & CVP:** edit example monthly costs and see the simple break-even estimate recalculate.

All data is demonstration data held in the page. There is no database, payment connection, or production inventory logic.

## View it with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages will publish the root `index.html` at:

https://tobey-m.github.io/tobeykatsu-pos/

The repository and published page are public.
